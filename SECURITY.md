# Security policy

This repository holds data and the scripts that validate and package it.
If you find a problem that could harm people using a release (for example a
way to tamper with a published catalog file), please do not open a public
issue. Report it privately: open the **Security** tab and choose **Report a
vulnerability**
(<https://github.com/thedude459/open-garden-data/security/advisories/new>).

Wrong or dangerous growing advice is not a security issue: open a
[plant data issue](https://github.com/thedude459/open-garden-data/issues/new/choose)
so it can be fixed in the open.

For vulnerabilities in the Open Garden app, see its
[security policy](https://github.com/thedude459/open-garden/security/policy).
